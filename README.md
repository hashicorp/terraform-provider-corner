# terraform-provider-corner
A Terraform provider of corner cases, used for testing Terraform and its SDK.

## How is this codebase used?

This repository is a testing fixture for automated tests in the following repositories:

* https://github.com/hashicorp/terraform-plugin-sdk
* https://github.com/hashicorp/terraform-plugin-framework
* https://github.com/hashicorp/terraform-plugin-go
* https://github.com/hashicorp/terraform-plugin-mux

There are real providers implemented in this repository, with their own acceptance tests written using `terraform-plugin-testing`, but none of them are released or user-facing. These providers cover the different broad types of providers that can exist in the ecosystem, with different combinations of pure-SDKv2, pure-Framework, muxed, protocol 5 vs 6, etc.

When automated tests run in the repos above, `terraform-provider-corner` is checked out from `main`. Then, `go mod edit` is used to replace a dependency with the code edited by the PR. For example, a PR updating the Framework will replace the terraform-plugin-framework dependency with that PR's edits and then run all of `terraform-provider-corner`'s tests. This means that any regressions introduced by changes to the repos above can be caught before they're merged. Look at the `.github/workflows/ci-go.yml` files in those repos to see how the testing process is defined.

Note: The `hashicorp/terraform-plugin-testing` repo itself is not tested using `terraform-provider-corner` in the way described above.
